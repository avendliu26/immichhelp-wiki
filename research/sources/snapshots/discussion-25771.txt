Hi all — I’ve published a small helper script to safely upgrade an Immich Docker Compose stack.
It was written and tested primarily on Synology DSM 7, but should work on most Linux hosts running Docker Engine + Docker Compose v2.
Key features:
Dry-run by default (explicit --run required)
Confirmation string includes the Compose project name
Optional Postgres backup via in-container pg_dump
Compose validation before any destructive actions
Label-checked cleanup to avoid cross-stack container issues
Graceful Ctrl-C handling with recovery hints
Release (v0.0.8):
https://github.com/jj12883/immich-docker-upgrade/releases/tag/v0.0.8
Repo:
https://github.com/jj12883/immich-docker-upgrade
Notes:
Targets Compose v2 (docker compose), not legacy docker-compose
Community-maintained — I’m unlikely to actively maintain it, but forks/PRs welcome
Hope it’s useful for anyone managing Immich Docker installs.

Hi All. First of all, I want to thank the Immich developers. I really appreciate everything you all have done and the hard work that goes on behind the scenes to continuously improve the project. Kudos to everyone involved!
I’m in a bit of a dilemma right now. I currently have a production Immich instance running in a Proxmox LXC that was deployed using the Proxmox Docker Community Script (
https://community-scripts.org/scripts/docker
). At the time I set it up, the Docker installation was the recommended and supported method.
I have Intel iGPU (N305) passthrough configured, bind mounts set up, and everything is working exactly as expected. My wife and I both use it as our primary photo library. Unfortunately, I don’t have any backups at the moment (I know… not ideal), and I don’t have another NAS to do a backup.
Ever since the Proxmox Community Scripts project released the dedicated Immich LXC, I’ve been tempted to switch over. Part of me says, “If it isn’t broken, don’t fix it,” but the tinkerer devil in me keeps saying, “Come on… do it.”
So I’d like to ask the community:
Is there any real benefit to migrating from my current Docker-in-LXC setup to the dedicated Immich LXC?
If you were in my situation, would you make the switch?
If I do decide to migrate, what’s the recommended approach? Which files and databases should I migrate so everything carries over correctly?
My biggest concern is making the migration completely transparent for my wife. Ideally, I’d like everything to remain exactly the same—same account, same password, same albums, same people, same memories, etc.—so she won’t even notice that anything changed.
I’d really appreciate hearing from anyone who’s made this migration. Thanks!

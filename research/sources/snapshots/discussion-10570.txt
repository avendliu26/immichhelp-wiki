damienallen
Sep 22, 2024
So, I had the same issue and I think I found one possible solution!
For those of us using docker compose, there used to be an
immich_microservices
container which was at some point deprecated. I noticed that it was mentioned as an orphaned container when running
up
which seemed normal at first (since it's no longer in my compose). However, when inspecting all my running containers I noticed that microservices was still running and erroring out often.
What worked for me was:
Stopping the
immich_microservices
container
Running
docker compose up -d --remove-orphans

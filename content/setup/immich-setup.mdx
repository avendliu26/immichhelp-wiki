## Direct answer

After the services start, register the first user, review storage settings, install the mobile app if needed, and configure a server backup. Immich's post-install guide treats the database and media backup as separate responsibilities.

## First login

The first user to register becomes the admin. Use the web endpoint shown by your deployment, then create other users from Administration when needed.

## Storage template

The storage template changes how uploaded filenames and folders are organized. If you change it for an existing library, use the documented Storage Template Migration job and keep a backup first.

## Mobile backup

From the mobile backup screen, choose the albums to upload and enable backup. Immich uses content checksums to skip files already on the server. iOS background execution and Android battery optimization can affect timing.

## Server backup

Follow the [backup and restore guide](/backup/immich-backup). A database dump contains metadata and paths, not the photos and videos themselves. Keep both layers and an off-site copy.
